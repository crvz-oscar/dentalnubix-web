# dentalnubix.com

Sitio público de Dental Nubix (fase piloto). HTML/CSS estático, sin build, publicado en GitHub Pages.

- `index.html`, `assets/`: la página principal. El contacto para clínicas piloto es un `mailto:` en `index.html`.
- `CNAME`, `robots.txt`, `sitemap.xml`, `llms.txt`, `404.html`: dominio y SEO.
- `docs/master-prompt-hostinger-seo.md`: prompt para dejar el DNS de Hostinger listo.

Al cambiar el estatus del producto, actualiza también el JSON-LD (FAQ y SoftwareApplication) de `index.html` y `llms.txt`.
